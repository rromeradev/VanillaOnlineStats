# Catálogo do agente 0.3.0

Baseline de todas as linhas: Paper 26.3-227 / Java 25; AuthMe 6.0.1-b2770. Owner técnico: módulo do agente indicado. Sem importação retroativa de eventos. Dados exportados não são públicos: a API futura deve aplicar autorização tenant/servidor/jogador e retenção no banco.

Spool opcional mantém os mesmos envelopes criptografados, com retenção máxima de cinco minutos e limite da fila. O estado latest local é limitado a 32 tipos e não é histórico. Reinício pode perder até dois segundos antes de checkpoint. Lacunas e descarte devem ser mostrados pelo futuro painel.

Provedores retornam valores desconhecidos como -1/unavailable ou lists de campos indisponíveis; não inferir rede/IO do processo, dados do cliente Minecraft nem custo por plugin a partir desses números. Player UUID não é prova de equivalência entre conta premium/offline. Reconciliação de identidade é tarefa explícita posterior.
