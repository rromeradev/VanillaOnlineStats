# Segurança

O agente 0.3.0 é validado em Paper 26.3 build 227 / Java 25 / AuthMe 6.0.1-b2770. API completa e painéis ainda estão em desenvolvimento. Limites e cobertura em docs/plugin/RELEASE-0.3.0.md; sem promessa de compatibilidade com outras combinações.

Não publique vulnerabilidades, credenciais ou dados pessoais em issues públicas. Use a opção **Report a vulnerability** na aba Security do GitHub quando disponível. Se indisponível, solicite ao mantenedor um canal privado sem divulgar detalhes técnicos publicamente.

Relatos devem incluir versão/commit, impacto e passos mínimos de reprodução com dados fictícios. Não há SLA de resposta definido nesta fase.
